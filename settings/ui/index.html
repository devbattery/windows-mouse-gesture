    움직이지 않고 이 시간 이상 누르고 있으면 제스처 대신 원래 우클릭으로 넘깁니다. 탐색기의 우클릭 드래그(복사·이동 메뉴)에 씁니다.

    길게 0.40초

    제스처를 쓰지 않을 앱

    여기 넣은 앱에서는 우클릭이 원래대로 동작합니다. 원격 데스크톱·가상 머신·그림 도구·게임에 권장합니다.

      알아 두면 좋은 점

      • 단축키는 실제 키 입력으로 보냅니다. 제스처를 시작한 창에서 Ctrl+T 같은 키를 누른 것과 같아서, 앱마다 결과가 다를 수 있습니다.
      • 크롬 확장 Glide를 함께 켜 두면 브라우저에서는 이 앱이 우클릭을 먼저 받아 확장이 동작하지 않습니다. 확장은 꺼 주세요. 브라우저는 확장으로 쓰고 싶다면 chrome.exe를 예외 앱에 넣으세요.
      • 관리자 권한으로 실행된 창(작업 관리자 등)에서는 위 상태 칸의 "관리자 권한 창 지원"이 켜져 있어야 동작합니다. 설치 스크립트로 설치하면 켜집니다.
